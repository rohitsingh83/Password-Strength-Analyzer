# data/common_phrases.txt
# -------------------------------------------------------------------------
# PURPOSE
#   A SMALL, educational list of famous phrases, quotations, lyrics and
#   proverbs that are *long* but still very predictable.
#
# WHY THIS FILE EXISTS
#   Length is the strongest single signal of strength, so a long phrase looks
#   excellent to a naive meter:
#
#       "correct horse battery staple"   ->  28 characters
#
#   Yet this exact phrase appears in every cracking wordlist and rule set in
#   existence (it comes from a well-known webcomic about passphrases), so it is
#   one of the first things an attacker tries. Length only helps when the
#   phrase is *your own*.
#
# HOW MATCHING WORKS
#   Matching is CASE-INSENSITIVE and separator-insensitive: spaces, hyphens,
#   underscores, dots and commas are removed before comparison, so
#   "Correct-Horse-Battery-Staple" and "correct horse battery staple" both
#   match the first entry.
#
#   Entries are stored with single spaces. Comments (#) and blank lines are
#   ignored by the loader.
#
# LICENSING / PROVENANCE
#   Only universally known public-domain proverbs, song titles, film lines and
#   generic security-industry examples are listed. No personal data, no leaked
#   credentials, no copyrighted lyrics of any length.
# =========================================================================
